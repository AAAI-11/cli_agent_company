# CLI Agent 伴侣 —— 项目目录结构说明

> 依据《cli_agent开题报告_修改版.md》整理的**标准硬件设计项目**目录结构。
> 主流程：需求 → 方案 → 硬件设计 → 固件开发 → PC 端服务 → 结构设计 → 测试验证 → 生产交付

## 目录总览

```
cli_agent_company/
├── 00_项目文档/              # 立项、需求规格、里程碑、会议纪要
├── 01_需求与方案/            # 功能需求分级（P0/P1/P2）、方案选型对比
├── 02_系统设计/              # 总体架构、通信协议、引脚分配、资源核算
├── 03_硬件设计/
│   ├── 原理图/               # 原理图工程（立创EDA / Altium / KiCad）
│   ├── PCB/                  # PCB 布局布线、Gerber 等制造文件
│   ├── BOM_采购清单/         # BOM 表、元器件选型与采购记录
│   └── 数据手册/             # 芯片 Datasheet（ESP32-S3/ST7789/INMP441/CH340C）
├── 04_固件开发/
│   └── esp32s3_firmware/     # ESP-IDF 工程（main + components + ota）
├── 05_PC端服务/
│   ├── agent_monitor/        # Agent 日志监听与状态解析
│   ├── mqtt_broker/          # MQTT Broker 配置（mosquitto/EMQX）
│   ├── asr_service/          # 语音识别服务（P1）
│   └── device_registry/      # 设备注册表与在线管理
├── 06_结构设计/
│   ├── 3D模型/               # FDM 外壳模型（STL/STEP/源文件）
│   └── 渲染图/               # 外壳效果图
├── 07_测试验证/
│   ├── 硬件测试/             # 电源/引脚/信号测试记录
│   ├── 固件测试/             # 各模块单元测试、板级测试
│   └── 整机测试/             # 端到端联调（Agent→PC→设备）、验收用例
└── 08_生产与交付/
    ├── 烧录与装配/           # 固件烧录指南、整机装配说明
    └── 演示与答辩/           # 演示视频/照片、结题报告、答辩 PPT
```

## 各目录放什么

| 目录 | 放什么 |
|---|---|
| `00_项目文档/` | 开题报告（当前在根目录，可移入）、需求规格说明书、里程碑/进度计划（MVP 2–3 周等）、每周例会纪要 |
| `01_需求与方案/` | 功能需求表（P0 状态可视化/Yes 确认/MQTT；P1 语音/主题；P2 多终端/小组件）、典型场景用例（专注编程/离开电脑/多任务）、方案选型对比（主控、屏、麦克风、外壳工艺） |
| `02_系统设计/` | 总体架构图（AI Agent ↔ PC 服务 ↔ ESP32×N）、MQTT 主题与 JSON 指令协议定义（`agent/device/{id}/cmd`、`.../event`）、引脚分配表、资源核算（GPIO/PSRAM/带宽） |
| `03_硬件设计/原理图/` | 原理图工程与导出 PDF/网表：ESP32-S3 最小系统、ST7789 SPI 屏、INMP441 I2S 麦克风、2 路按键（上拉+消抖电容）、CH340C 一键下载、Type-C 供电 |
| `03_硬件设计/PCB/` | PCB 布局布线文件、Gerber/钻孔文件、打样（嘉立创等）下单记录、焊接注意事项 |
| `03_硬件设计/BOM_采购清单/` | BOM 表（位号/型号/封装/数量/单价/采购链接/到货状态）：ESP32-S3-8M PSRAM 模组、2.8" ST7789 屏、INMP441、CH340C、按键、Type-C 座等 |
| `03_硬件设计/数据手册/` | 各芯片/模组官方 Datasheet 与参考原理图（乐鑫、中景园屏、INMP441、沁恒 CH340C） |
| `04_固件开发/esp32s3_firmware/main/` | ESP-IDF 主工程：5 个 FreeRTOS 任务（LvGL 渲染、按键中断+消抖、I2S 音频采集、Wi-Fi/MQTT、指令解析分发）、事件队列/信号量 |
| `04_固件开发/esp32s3_firmware/components/` | 组件库：`lvgl_ui`（表情/主题）、`st7789`（SPI+DMA 驱动）、`audio`（INMP441 环形缓冲）、`network`（Wi-Fi 断线重连）、`mqtt`、`protocol`（JSON 编解码） |
| `04_固件开发/esp32s3_firmware/ota/` | OTA 无线升级：分区表、服务器/固件包、升级脚本与版本记录 |
| `05_PC端服务/agent_monitor/` | 监听 Claude Code/Cursor/Aider 日志或回调 → 解析工作状态 → 生成 JSON 指令的 Python/Node.js 代码 |
| `05_PC端服务/mqtt_broker/` | Broker 安装与配置（mosquitto.conf / EMQX）、主题与 ACL 设置、启动脚本 |
| `05_PC端服务/asr_service/` | P1 语音识别：ASR 服务选型（本地 whisper / 云端 API）、音频流转发与文本注入 Agent 的代码 |
| `05_PC端服务/device_registry/` | 在线设备注册表（ID/IP/连接状态/显示角色）、按角色过滤下发的逻辑、可选 Web 管理面板 |
| `06_结构设计/3D模型/` | 外壳 3D 模型源文件与导出 STL（预留屏幕窗口、2 键、Type-C 开孔），FDM 打印切片参数 |
| `06_结构设计/渲染图/` | 外壳渲染效果图、实物照片 |
| `07_测试验证/硬件测试/` | 上电/电源测试、引脚信号测量（SPI 波形、I2S 时钟）、按键消抖验证记录 |
| `07_测试验证/固件测试/` | 各任务/模块单元测试、LvGL 界面测试、OTA 升级测试 |
| `07_测试验证/整机测试/` | 端到端联调用例（Agent 状态切换→屏幕显示、Yes 按键→回传确认）、MVP 验收清单 |
| `08_生产与交付/烧录与装配/` | 固件烧录步骤（esptool / IDF 一键下载）、整机装配说明、BOM 核对表 |
| `08_生产与交付/演示与答辩/` | 演示视频、项目照片、结题报告、答辩 PPT、课程知识点覆盖清单对照 |

## 建议

- 代码工程（`esp32s3_firmware/`、`05_PC端服务/` 内部）建议用英文命名，避免工具链对中文路径的兼容问题；文档类目录用中文无碍。
- 每个空目录已放 `.gitkeep`，git 会保留目录；把文件放入后即可删除对应 `.gitkeep`。
- 里程碑对应：**MVP（P0）** 涉及 `01/02/03/04/05/07` 的最小闭环；**P1** 加 `asr_service` 与主题；**P2** 加多终端与小组件，主要落在 `05` 与 `04` 的 UI 部分。
