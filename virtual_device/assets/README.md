# 形象素材槽（给 R3）

往本目录丢 PNG 即可替换虚拟设备的宠物，**不用改任何代码**。

## 规则

| 文件名 | 替换的状态 |
|---|---|
| `thinking.png` | 思考中 |
| `working.png` | 干活中 |
| `waiting_confirm.png` | 等你拍板 |
| `done.png` | 完成 |
| `error.png` | 出错了 |

- **尺寸**：正方形，建议 352×352（显示为 176×176，2 倍图保清晰）
- **背景透明**，主体居中占满；该状态的**表情/姿态直接画进图里**（代码侧保留光晕、上下浮动、状态徽标和底部文字）
- **缺哪张用哪张的矢量小狗兜底**——可以一次只画一张，渐进替换
- 命名必须与状态名完全一致（含下划线）

## 为什么这么做

未来 ESP32-P4 固件（LVGL）同样按"每状态一张素材"从 flash 加载——
这里的 PNG 产出之后可以平移到固件资源里，美术工作不做两遍。
