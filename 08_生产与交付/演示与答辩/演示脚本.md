# 演示脚本(5 分钟版)

> 口径:现场一根 USB 线连实体板,零网络依赖(whisper 本地推理、无云服务)。
> 目标观众:评委/老师。叙事主线:**CLI Agent 的物理伴侣**——状态看得见、权限摸得着、语音说得出。

## 〇、环境一键启动(上台前 15 分钟,逐条复制执行)

> 4 个终端窗口 + 1 个浏览器页面。每条命令独立一行,直接复制粘贴。
> 目录约定:`~/project_lh/cli_agent_company` 是仓库根,下称**仓库根**。

**终端 1 —— 起 daemon(主心骨,先起)**:

```bash
cd ~/project_lh/cli_agent_company/daemon && npm run demo
```

> `npm run demo` 带语音播报(`PETLINK_VOICE=1`,Mac `say` 发声,演示时"它会开口"就靠它)。
> 起来后**不要动这个窗口**,后面所有 curl 在别的窗口敲。

**终端 2 —— 起 tmux 演示会话(语音注入的靶子)**:

```bash
tmux kill-session -t voicetest 2>/dev/null; tmux new -s voicetest
```

> 进 tmux 后,**在 tmux 里**跑 claude(语音注入要求 claude 跑在 tmux 的 pane 里):

```bash
claude
```

**终端 3 —— 备用指挥窗口(所有 curl 在这敲,留着别关)**:

```bash
cd ~/project_lh/cli_agent_company
```

**浏览器** —— 打开虚拟设备:

```
http://localhost:7331/device
```

> Cmd+Shift+R 硬刷新一次,确保不是旧缓存页面。

**最后一步(关键)—— 重启一次 daemon 拿干净计数**:终端 1 按 `Ctrl+C` 停掉,重跑:

```bash
npm run demo
```

> 这样 `/stats` 演示数字从零起算,板子重连约需 5 秒。

## 二、演示流程(计时)

### 0:00–0:30 开场:一实一虚,同源同协议

> "这是 Claude Code 的桌面伴侣。左手实体板,右手浏览器虚拟设备——**同一个自研
> PetLink 协议驱动**,daemon 一跳广播,两边状态永远一致。"

动作:手举实体板 + 切浏览器虚拟设备页,让两边同屏出现同一状态。

### 0:30–1:30 F01 状态可视化:让 Agent 干活

动作:在 tmux 里给 Claude Code 一个真实任务(如"看看这个目录有多少行代码")。

- 屏幕流转:**思考中(头顶 … 循环)→ 干活中(双弧旋转)→ 完成(星轨)**
- 状态胶囊下方还有**实时短标签**(当前工具名/阶段),文本与 PNG 素材槽 v0.3 起支持

兜底(没有真 Agent 会话时,手动喂事件,效果完全相同):

```bash
curl -s -X POST localhost:7331/state -H 'Content-Type: application/json' -d '{"event":"UserPromptSubmit","session_id":"demo","prompt":"统计代码行数"}'
curl -s -X POST localhost:7331/state -H 'Content-Type: application/json' -d '{"event":"PreToolUse","session_id":"demo","tool_name":"Bash"}'
curl -s -X POST localhost:7331/state -H 'Content-Type: application/json' -d '{"event":"Stop","session_id":"demo"}'
```

### 1:30–3:00 F03 实体键授权仲裁(核心创新点)

动作:让 Claude Code 执行一个需要授权的操作(或用挂起请求模拟):

```bash
curl -s -X POST localhost:7331/permission -H 'Content-Type: application/json' -d '{"tool":"Bash","prompt":"rm -rf build"}'
```

- 屏幕切**等待授权**(O 嘴 + ! 脉冲,宠物下沉不安)——**curl 挂着,裁决权在板子上**
- **按 YES 短按** → 终端返回 `{"behavior":"allow"}`,屏幕回干活态
- 再挂一次 → **按 NO** → 返回 deny(带拒绝原因 message)
- 再挂一次 → **什么都不按** → 15s 超时回落 Claude Code 正常弹窗(语义:无决策,
  绝不替用户做主)——设备同时自动回 thinking,不会卡死在等待态

> 口播:"权限请求从屏幕弹窗变成手边实体键。离开键盘的拍板时机,一个按键拿回来。
> 超时兜底设计保证了**增强而非劫持**。"

### 3:00–4:00 F14 语音输入:对着板子说话

动作:距板 ~30cm,**按住 VOICE 键**,说"帮我看看当前目录下有哪些文件",**说完松手**。

- 屏幕:录音中(按住期间)→ 语音已发送 → 完成
- daemon 日志/终端:`[voice-in] ... 语音已注入 pane=voicetest:0.0: "帮我看看当前目录下有哪些文件"`
- 链路:ES8311 codec 录音(16k/16bit,按住多长录多长,上限 30s)→ USB 上行
  → **本地 whisper 转写** → tmux 注入,松手后 <1s 出文字

> 口播:"语音不走云端——whisper 在本机推理,断网照样工作。"

### 4:00–4:30 F17 摇杆导航 + F12 语音播报(顺带展示)

> 摇杆引脚已定档烧录(X=GPIO21,v0.9.0 固件自带,无需现场配置)。
> 第二个会话没有真 claude 时,用这条 curl 造(然后推杆切换看气泡/终端跟跳):

```bash
curl -s -X POST localhost:7331/state -H 'Content-Type: application/json' -d '{"event":"UserPromptSubmit","session_id":"demo2","prompt":"第二会话"}'
```

**时序提醒**:并排气泡要求两个会话同时"活"——working 态能撑 10 分钟,
done 保留 3 分钟(2026-09-18 从 60s 调宽,够讲解过渡)。晾超 3 分钟再开
第二个,屏上就只剩一颗(TTL 退场,不是坏了)。稳妥顺序:第一个任务完成
后 3 分钟内起第二个。

动作:tmux 里再开一个窗口跑第二个 Claude Code 会话(或 curl 造第二会话),
**摇杆左右推**:

- 屏上焦点气泡双向切换;**Mac 终端自己跳到焦点会话所在的 tmux 窗口**
  (daemon `select-window`/`select-pane` 同步——"摇杆在手,屏幕和终端一起翻")
- 摇杆切到哪个会话,按住 VOICE 说话就注入到哪个会话(注入跟焦点走)
- 状态切换时 daemon `say` 播报自然发声,指出即可:"完成时它还会开口告诉我。"

> 口播:"多会话不迷路——一只摇杆把焦点和终端视图一起翻,语音也跟着焦点走。"

### 4:30–5:00 F13 会话统计 + 收尾

```bash
curl -s localhost:7331/stats | python3 -m json.tool
```

> 演示中随时核对面板(不占演示时间,评委看屏的空档敲):

```bash
curl -s localhost:7331/status
```

> 口播:"整个会话的画像:各状态时长、授权 allow/deny 次数、语音输入字数——
> 这台设备不只是玩具,是可度量的工作伴侣。"

收尾一句话回叙事:"状态看得见、权限摸得着、语音说得出——全部开源,git 历史可证。"

## 三、风险与兜底预案

| 环节 | 挂相 | 处置 |
|---|---|---|
| 板子不连/黑屏 | 屏幕卡"连接中" | 拔插 USB(≤90s 自愈);实在不行**虚拟设备全程可顶**(同协议) |
| 授权挂起无人按键 | — | 15s 自动回落弹窗,不是事故是设计,顺势讲兜底语义 |
| whisper 转写错字 | 个别字不准 | small 模型预期内;说短句、正常音量、30cm |
| 录音没触发 | 按成了 YES(旁边那颗)/授权等待中 | 认准第三颗 VOICE 键,宠物回空闲态再按 |
| USB 双向静默(Mac/CH343 偶发) | hello 风暴/掉线 | 重启 daemon 5s 自愈;演示前重启一次可显著降概率 |
| 终端注入没看到 | tmux pane 选错 | 演示前 `curl -s localhost:7331/inject/panes` 核对 pane 号 |

**黄金法则:任何一环挂了都能 30 秒内切兜底路径继续,演示不断链——这本身也是
"增强通道尽力而为、主链路绝对可靠"的架构卖点。**
